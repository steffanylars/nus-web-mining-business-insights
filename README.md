# BT4222 Group 13: Personalised Product Search on JDSearch

Re-ranking the products JD retrieves for a search query, using the current query, product metadata and each
shopper's preceding clicks, carts and orders. Main model: DHAR (Dual-Horizon Attention Ranker), compared with
popularity, SVD, history-conditioned CF and LambdaMART on the same users, slates and metrics (NDCG@10, MRR, P@1, HR@10).

## 2. Datasets

| Dataset | Purpose | Content | Used in |
|---|---|---|---|
| JDSearch raw files (user log and product file) | Source data | Queries, candidate slates, labelled clicks/carts/orders, preceding user histories with time gaps, anonymised product metadata | Steps 1 and 2 |
| Sampled modelling tables (`candidates`, `history`, `sessions`, `meta_subset`) | Cleaned/intermediary data | 20,000 users drawn with seed 42, split by user 70/15/15 | Steps 2 to 7 |
| Feature table (`features.parquet`) | Engineered features | 26 numeric features per query-product pair | Steps 3 to 7 |

* **Raw data:** not redistributed. Download it from the official repository, https://github.com/rucliujn/JDsearch.
* **Intermediary tables:** regenerated by Steps 1 to 3 from the raw files. Their split fingerprint is stored in
  `artifacts/corrected/dataset_manifest.json` and checked in Step 2. The small ones (`candidates`, `history`,
  `sessions`, `features`) are committed under `Final Project/data/intermediate/` so Steps 3 to 7 run without the
  raw files; `meta_subset.parquet` (409 MB) is regenerated with Steps 1 and 2.
* **Committed outputs:** `artifacts/corrected/` holds every metric and prediction file reported in the final
  report; `artifacts/step7_corrected/` holds Step 7 re-run on the corrected features.

## 3. Source code and outputs

| Step | Notebook | Purpose | Main outputs |
|---|---|---|---|
| 1 | `Step1_Temporal_Analysis.ipynb` | Converts time gaps into event ages for all 26.7M events and measures the logging window of each action type | `temporal_type_by_daybin.csv`, `retention_cutoffs.txt` |
| 2 | `Step2_Build_Dataset.ipynb` | Samples 20,000 users, builds candidate and history tables, splits by user | `dataset_manifest.json`, `sessions.parquet` |
| 3 | `Step3_Feature_Engineering Final.ipynb` | Builds 26 features (short-intent, order history, query fit, train-only popularity priors) | `feature_summary.json`, `horizon_coverage.json` |
| 4 | `Step4_Baselines_LambdaMART.ipynb` | Random, popularity, content, SVD and LambdaMART rankers | `results_baselines_lgb.json`, `lgb_model.txt` |
| 5 | `Step5_Neural_Rankers_DHAR.ipynb` | DHAR and matched neural controls (MLP, pooled, short-only, order-only, history CF) | `results_neural.json`, `training_*_seed42.json` |
| 6 | `Step6_Diagnostics.ipynb` | Ablation, paired bootstrap, subgroup and rank-by-action analysis | `ablation.json`, `paired_bootstrap.json`, `segment_metrics.csv` |
| 7 | `Step7_ColdStart_Diversity.ipynb` | History-free fallback routing and category diversification | `results_coldstart_diversity.json`, `diversity_tradeoff.csv` |

Each notebook has **Part A** (the stage's code, explained cell by cell) and **Part B** (reads the committed
outputs in `artifacts/corrected` and re-checks the reported numbers, with no raw data needed).

## 4. How to run

* **Google Colab (GPU recommended for Step 5):** open a notebook from `Final Project/notebooks/`. The first cell
  clones this repository (`BRANCH = "main"`). Set `MOUNT_DRIVE = True` if the raw files are in Google Drive, then
  run Steps 1 to 7 in order.
* **Locally:** `pip install -r "Final Project/requirements.txt"`, set `JD_USER_TXT`, `JD_PRODUCT_TXT` and a new
  `JD_RUN_DIR`, then `python "Final Project/src/run_pipeline.py"`.
* **Tests:** `python -m unittest discover "Final Project/tests"`.

## 5. Key results (test set, 2,965 queries)

| Model | NDCG@10 |
|---|---|
| Popularity | 0.3045 |
| SVD (train-only fold-in) | 0.2759 |
| History-conditioned CF | 0.2694 |
| LambdaMART (26 features) | 0.3630 |
| MLP, same features | 0.3725 |
| DHAR (ours) | 0.3713 |

* The time-aware features raise the same LambdaMART from 0.3387 to 0.3630.
* DHAR beats LambdaMART (+0.0083, 95% CI [+0.0022, +0.0145]) but not the same-feature MLP (-0.0012, CI includes zero).

Full tables are in `Final Project/artifacts/corrected/RESULTS.md`.
